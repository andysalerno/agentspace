## Programming practices

### Python

- Use `uv` as the package manager and python env manager
- Use strict type-checking with pyright
- Use `ruff` for formatting and linting, with all defaults enabled
- Create tests as you go
- Use modern features and idiomatic practices
- Add logging via logging module

### Rust

- Use the latest edition: Rust 2024
- Use clippy for static analysis with all defaults enabled
- Use clippy for formatting
- Create tests as you go
